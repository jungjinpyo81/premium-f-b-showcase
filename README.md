# Premium F&B Showcase

웹사이트 프론트엔드 및 히어로 섹션 프롬프트] "상위 0.1% B2B 클라이언트를 타겟으로 하는 프리미엄 F&B 에이전시의 웹사이트 메인 페이지를 구축해 줘. 전체적인 디자인은 매거진형 레이아웃을 따르며, 산만하게 느껴질 수 있는 화려한 웹 모션은 모두 제거해 줘. 대신 정제된 타이포그래피와 고품질의 정적 이미지를 활용하여 신뢰감과 무게감을 줘야 해. 히어로 섹션에는 텍스트와 배경 이미지가 고급스럽게 어우러지도록 구성해 주고, 비즈니스 효율을 높일 수 있는 스마트 문의 폼과 연결되는 직관적인 CTA(Call to Action) 버튼을 배치해 줘."

[관리자 페이지 텍스트 에디터 기능 확장 프롬프트] "관리자(Admin) 페이지 내에서 브랜드 스토리와 물류 정보를 직접 입력하고 수정할 수 있는 텍스트 에디터 컴포넌트를 확장 개발해 줘. 입력되는 텍스트의 디자인적 완성도를 높이기 위해 다양한 폰트 패밀리를 선택할 수 있는 기능과 텍스트 정렬(좌측, 중앙, 우측, 양쪽 정렬) 버튼을 추가해 줘. 코딩을 몰라도 에디터 내에서 시각적인 서식 조정이 완벽하게 이루어지도록 UI를 직관적으로 구성해 줘."
