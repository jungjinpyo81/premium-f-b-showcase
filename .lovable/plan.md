# GNB 드롭다운 및 PC 풀페이지 스크롤 조정

## 변경 내용
- 데스크톱 GNB의 각 메뉴를 서로 독립된 항목으로 분리합니다.
- 하위 메뉴는 포인터가 **맛의 여정** 항목 위에 있을 때만 열리고, 다른 메뉴로 이동하면 즉시 닫히도록 합니다.
- 맛의 여정 하위 메뉴로 포인터를 옮기는 동안에는 메뉴가 유지되도록 합니다.
- 메인과 맛의 여정 페이지의 한 화면 단위 스크롤 효과를 PC(`lg`, 1024px 이상)에만 적용합니다.
- 태블릿과 모바일에서는 일반 연속 스크롤을 유지합니다.

## 확인
- PC에서 맛의 여정만 하위 메뉴를 여는지 확인합니다.
- PC에서 휠 스크롤 시 다음 섹션으로 한 화면씩 정렬되는지 확인합니다.
- 태블릿·모바일에서 스크롤 스냅이 비활성화되는지 확인합니다.
